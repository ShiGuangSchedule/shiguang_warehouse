# XJNU 适配验证

适配文件为 `resources/XJNU/xjnu.js`。测试使用虚构课程、教师和教室，不包含学生账号、密码、登录会话或真实课表页面。

```sh
npm ci --prefix tests/xjnu --ignore-scripts
npm test --prefix tests/xjnu
```

覆盖隐藏详细课程块、重复格子、三节连堂、不连续节次、单双周、不同星期列顺序、缺少教室、教学周历、取消操作、保存失败和登录失效。还验证五套官方作息、跨楼宇和跨校区错峰、楼名确认、历史学期、第 11/12 节回退、作息保存失败及保留原作息。网络请求只访问学校同源，不调用课表配置保存接口。

## 在拾光中测试

已发布版本可从自定义仓库的 `main` 分支更新，在学校列表中直接选择“新疆师范大学”，步骤见 [安装与导入](../../resources/XJNU/README.md#安装与导入)。下面的测试入口用于尚未发布索引的开发版本。

1. 在“更多”页开启开发者功能。不同版本按钮位置可能略有变化，2.x 通常为点击图标五次。
2. “我的 → 更多 → 更新教务适配仓库”，选择自定义仓库。
3. 仓库填写 `https://github.com/CkYtxwz/shiguang_warehouse.git`，分支填写 `test/xjnu`。
4. 更新后，进入“教务系统导入 → 通用工具 → 适配代码测试”。
5. 输入 `https://jwxt.xjnu.edu.cn/jsxsd/`，在学校页面内登录，进入学生首页后点击“执行导入”。
6. 选择学期和默认作息，并为提示的楼宇确认所属方案；选择“保留目标课表现有作息”则继续沿用自己的时间。建议先导入到单独的新课表。
7. 核对预览中的逐节时间和楼宇对应，然后导入。核对课程、单双周、连堂节次、教室；错峰课程需在课程详情核对自定义起止时间，侧栏使用默认作息。
8. 根据完成提示核对第一周开始日期和总周数。脚本只显示学校教学周历，不覆盖现有配置。

`test/xjnu` 是维护者 Fork 专用的手机测试分支，额外包含 `resources/GLOBAL_TOOLS/test.js`。该文件是正式脚本的相同副本，用于现有测试入口，不需要重新发布学校索引。

正式贡献应提交到官方仓库的 `pending` 分支；不要把测试分支的 `test.js` 提交到上游 PR。

## 支持范围和边界

- 新疆师范大学本科教务系统的个人“学期理论课表”。
- 用户自行登录，使用同源 Cookie；脚本不接收或存储账号密码。
- 按真实节次和周次导入，支持 2025 年春季起的官方作息及楼宇错峰；也可保留原作息。默认课时长度和学期配置不覆盖。时间来源及完整对照表见 [适配说明](../../resources/XJNU/README.md)。
- 暂无排课时间的记录会提示，不会编造星期或节次。部分课程可能同时有已排课和未排课记录。
- 未覆盖研究生系统、教室课表、WebVPN 或其他域名入口。
- 维护者于 2026-10-31 确认，基础课程导入和新增的校区、楼宇错峰作息均已完成手机验收。该日期为验收结果确认日期；自动化测试另行覆盖桌面解析和模拟桥接流程。
