# 新疆师范大学本科课表适配

使用已登录的本科教务页面读取个人“学期理论课表”，不接收、保存或上传账号、密码及 Cookie。

## 安装与导入

维护者已发布的自定义仓库地址为 `https://github.com/CkYtxwz/shiguang_warehouse.git`，代码分支为 `main`，编译后的学校索引位于 `index-pb-release`。

在拾光的“更新教务适配仓库”中选择自定义仓库，填入上述地址和 `main` 分支并更新。进入“教务系统导入”，搜索“新疆师范大学”，选择本科教务适配即可自动打开学校登录页，无需另填教务地址。登录后执行导入，核对学期、课程和作息预览。

上述自定义入口属于维护者的发布版本；官方源是否收录，以官方仓库的合并与索引发布状态为准。修改 YAML 后必须重新编译并发布索引，单独更新脚本不会新增学校入口。

## 导入时的处理

1. 选择学期后，选择默认作息；也可保留目标课表原有作息。
2. 对起止时间受错峰影响的课程，明确包含校区和官方楼号的教室可直接识别。“文史楼”也可识别；其他名称、未注明校区的“2号教学楼”或没有教室的课程会要求确认方案。同一楼名只确认一次，不猜测楼名别称与编号的对应关系。
3. 预览显示默认十节时间、各楼宇选择和错峰安排数量。确认后保存课程，再保存默认作息。
4. 与默认作息起止时间不同的课程通过拾光的自定义时间字段保存，仍保留原节次、周次等信息。请在课程详情核对自定义时间；课表侧栏显示的是默认作息。
5. 若作息保存失败，明确提示“课程已保存，但学校作息未能写入”，不会提示全部成功。桥接接口不提供跨课程与作息保存的事务或撤销能力。

官方文件只覆盖第 1—10 节。如课程出现第 11 节及以后，或导入 2024—2025 第一学期及更早学期，整个导入会保留已有作息并说明原因，不套用不适用的时间。

脚本不调用 `saveCourseConfig`，避免重置已有课表配置；第一周日期、总周数仍从学校教学周历读取后提示手动核对。默认课时/课间长度不影响本次保存的逐节起止时间，后续手动生成节次时应另行检查。

开发与手机测试步骤见 [测试说明](../../tests/xjnu/README.md)。
