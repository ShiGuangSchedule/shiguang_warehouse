# 东北林业大学本科课表适配

## 简介

本适配器面向本部本科生院，读取强智教务的个人课表。用户登录后选择学期，即可导入整学期课程。

适配范围不包含海南国际学院、研究生和 WebVPN。适配器名称标明使用范围，脚本不额外核验用户身份。

## 使用方式

1. 在学校列表中选择“东北林业大学”。
2. 打开“东北林业大学本部本科生院”，完成教务登录。
3. 点击拾光应用（App）的导入按钮，选择目标课表。
4. 选择教务学期，等待课程保存完成。

默认学期来自教务页面的选中项，不一定是列表首项。查询使用页面提供的本部作息选项；选项名称变化时，沿用教务默认值。

本次导入只更新课程，保留原有作息和学期设置。使用者应核对目标课表的开学日期、总周数和单节时间。

课程保存沿用 App 的覆盖流程，不增加确认弹窗。正常空课表会提交空数组，已有课程也会相应清空。建议首次测试时新建课表。

## 数据处理

- 使用现有登录会话，只发送同源 GET 请求。
- 从 `xskb_list.do?viweType=0` 读取完整个人课表。
- 从页面选项获取学期和作息编号，不硬编码编号。
- 通过合并单元格的占位关系确定星期。
- 从课程文字读取周次和节次，支持单双周及跨小节课程。
- 只使用 HTML 的单双周信息，不使用明细 JSON 的单双周标签。
- 按名称、教师、地点和星期分组，逐周合并连续节次。
- 再将相同时段的周次汇总，保留调课产生的差异。
- 未排具体时间的备注只提示查看，不生成虚构排课。

脚本使用拾光 V2 桥接。学期选择返回 `null` 时终止；索引 `0` 是有效选择。请求或解析失败时报告错误，保存成功后才发送完成信号。

脚本不调用 `savePresetTimeSlots` 或 `saveCourseConfig`。大节钟点不足以推算小节作息，查询周数也不等于教学周数。

## 本地测试

在仓库根目录运行以下命令。测试服务器需要 Node.js，测试页面需要现代浏览器。

```sh
node --check resources/NEFU/nefu.js
node tests/NEFU/serve.cjs
```

打开终端打印的本地地址，查看测试结果。结束后按 Ctrl+C 停止服务器。端口默认为 8766，可通过环境变量 `PORT` 修改。

测试直接加载正式脚本，使用浏览器原生 DOMParser。样本均为虚构数据，桥接和网络请求均使用模拟实现。

测试覆盖以下内容：

- 跨行课表、同格多课、单双周和不连续节次。
- 课程字段缺失、结构变化、登录页和错误响应。
- 周次及节次合并，以及 1,000 组随机数据的语义一致性。
- 学期默认值、首项选择、取消操作和正常空课表。
- V2 参数类型、单次保存、保存失败和完成通知顺序。
- 浏览器直接执行脚本时的自动入口。

索引检查可沿用仓库的 `scripts/build_data.py`。构建依赖 PyYAML 和 protobuf；生成的二进制文件不属于本适配器源码。

## 验证记录

2026 年 9 月 26 日，浏览器回归测试通过 73 项检查。索引构建及序列化往返检查通过，新增学校和适配器各 1 项。

真机验证使用小米平板 5（nabu）和拾光 2.0.0，测试目标为独立课表。验证结果如下：

- 非空学期：25 张课程卡片合并为 24 条记录，成功保存 159 条课程周次记录。
- 数据一致性：逐周、逐节展开后，328 个上课单元的校验值一致。
- 取消选择：课程数据保持不变。
- 正常空课表：成功提交空数组，目标课表课程清空。
- 配置保留：导入未修改作息、开学日期和学期总周数。

课表需要正确的开学日期，才能按周显示课程。首次导入后界面空白时，应先核对日期、所选周次和目标课表。

真机测试使用本地部署的正式脚本和学校登记，未发布远端索引。验证仅覆盖该设备和已授权本科账号，不代表其他校区或所有设备均已验收。

## 提交与测试分支

适配文件包含学校登记、适配器配置和脚本。回归测试位于 `tests/NEFU`，不随脚本执行。

开发分支基于上游 `pending`，本次仅推送个人仓库。不创建上游拉取请求（PR）。后续如提交 PR，目标分支应为 `pending`。

修改 YAML 后，App 需要更新编译后的学校索引。索引由手动工作流发布，推送代码不会自动更新学校列表。
